## 1. 项目总览与定位

LightGuard 是纯用户态、无内核驱动、无蓝屏风险、零广告、可开源的 Windows 内网安全 + 加密容灾 + 行为审计一体化工具。

### 解决行业四大痛点

1. 传统安全软件体积臃肿、驱动冲突蓝屏、频繁误拦截；
2. 普通备份工具无加密，局域网内共享文件可随意查看，勒索病毒会同步加密备份文件；
3. 文件服务器缺少操作追溯，文件拷贝、删除、修改、外泄行为无任何记录；
4. 仅能事后查杀病毒，无法提前识别勒索异常行为，损失无法规避。

### 项目硬性设计约束

- 不做全盘病毒扫描、不搭建程序沙箱、不使用内核 Hook 驱动；
- 核心能力聚焦：异常行为检测、文件特征核验、防火墙流量管控、系统广告净化、加密分片备份、灾难数据恢复、服务器操作审计；
- 全平台兼容 x86/x64/ARM64，适配 Win10/11 客户端、Windows Server 2019/2022 文件服务器。

## 2. 旧版缺陷与完整修复方案

### 勒索防御依赖网络，断网无防护
**修复**：内置离线行为基线规则 + 本地 YARA 勒索特征库，断网环境可持续防御。

### 无主动行为识别，仅依靠事后备份补救
**修复**：对接 Windows 原生 ETW 事件追踪，实时捕获文件异常操作，提前拦截勒索行为。

### 程序更新无校验，存在劫持投毒隐患
**修复**：全文件采用 RSA2048 签名校验 + SHA256 哈希校验，任何文件篡改都会拦截拒绝运行。

### 架构单一仅支持 x64，无法适配服务器与 ARM 设备
**修复**：全架构统一适配，客户端、服务器、低功耗 ARM 主机均可部署运行。

## 4. ETW+YARA 双层勒索防御体系（原创架构）

### 4.1 ETW 行为监控（拦截未知勒索程序）

实时监控高危风险动作：批量篡改文件后缀、短时间大量加密写入、遍历全盘目录、删除 VSS 卷影副本、批量移动加密文件；

风险触发后自动执行：主机断网、挂起恶意进程、弹窗高危告警、锁定系统卷影备份。

### 4.2 YARA 特征核验（精准识别已知勒索病毒）

不进行全盘扫描，仅行为异常触发后对目标文件按需扫描，极低资源占用；

内置离线勒索规则库，支持签名校验后的规则在线更新；

优化规则阈值，大幅降低正常软件误报概率。

### 双层防御逻辑

ETW 捕获未知异常行为 + YARA 匹配已知病毒特征，轻量化实现勒索病毒事前拦截，区别于传统杀毒软件事后查杀模式。

## 5. 全域广告屏蔽模块（三层净化机制）

- **Hosts 全局域名拦截**：自动备份 / 还原 Hosts 文件，刷新 DNS 缓存，阻断广告域名访问；
- **防火墙程序流量拦截**：限制 WPS、影音软件、下载工具等流氓程序广告联网行为；
- **系统注册表配置**：批量关闭 Win10/Win11 系统内置推送广告、弹窗推荐；
- 所有拦截规则支持签名校验更新，内置白名单机制避免业务程序误拦截。

## 6. 落尘原创 | 局域网私有加密抗勒索备份体系（核心重磅）

### 核心解决两大痛点

1. SMB/NAS 局域网内其他人员获取备份文件后无法读取明文数据；
2. 勒索病毒无法识别、篡改、加密备份包，保障灾难恢复介质安全。

### 6.1 加密算法套件（工业安全标准）

- 文件存储加密（默认）：AES-256-GCM，同时完成加密与完整性校验，篡改任意字节解密直接失败；
- 低性能 CPU/ARM 设备自动切换：ChaCha20-Poly1305；
- 国密合规可选：SM4 对称加密算法；
- 密钥派生算法：PBKDF2-HMAC-SHA256，10 万次迭代 + 随机盐值，抵御彩虹表暴力破解；
- 完整性校验：分片独立 SHA256 哈希 + 备份包全局哈希双重校验；
- 传输加密：SMB over TLS1.3 隧道加密，局域网抓包无法窃取传输文件；
- 团队权限隔离（高级功能）：RSA2048 公私钥分离，公钥存放服务器加密备份密钥，私钥仅管理员持有。

### 6.2 抗勒索专属原创机制

- 自定义私有备份后缀 `.lgbackup`，勒索程序无法识别文件格式，不会对备份包进行加密；
- GCM 校验机制，备份文件被修改后直接标记损坏，拒绝恢复；
- 解密密钥仅保存在本地客户端，不会上传存储至局域网文件服务器。

### 6.3 五层全粒度备份支持

1. **单文件备份**：凭证、配置文件、单据、密钥等小型核心文件；
2. **目录备份**：桌面、项目工程、文档库、网站站点目录，支持过滤缓存、临时垃圾文件；
3. **分区镜像备份**：C 盘系统盘、D 盘数据盘，依托 VSS 卷影副本实现占用文件热备份；
4. **整块硬盘镜像备份**：扇区级完整镜像，适用于整机迁移、硬盘硬件故障整机救援；
5. **数据库专项备份**：支持 SQLite、MySQL、MariaDB、SQL Server、Access，支持整库、单表、事务日志增量热备份。

### 6.4 备份策略体系

全量备份、增量备份、差异备份、增量自动合并全量；支持 SMB 断点续传、传输速度限速、服务器离线本地缓存、上线后自动同步至 NAS。

### 6.5 备份生命周期自动管理

- 按保留份数清理：仅留存用户设定数量的最新备份；
- 按时长清理：按 7/30/90 天周期自动清理过期备份；
- 核心备份锁定：重要全量备份开启保护，自动清理规则不会删除锁定文件；
- 清理全程写入审计日志。

### 6.6 备份 & 还原双端可视化进度条

- 备份进度：实时百分比、读写速度、已处理/总文件数量、占用容量、预估剩余时间、加密处理状态、当前处理文件路径；
- 还原进度：解密进度、分片写入进度、完整性校验进度、剩余耗时；
- 后台最小化后托盘悬浮微型进度窗口。

## 7. 全链路解密灾难恢复系统

### 7.1 三种安全恢复模式

- **隔离恢复（默认安全）**：恢复至全新空白目录，不会覆盖本机现有文件；
- **增量恢复**：仅还原版本更新变更的文件，节省耗时；
- **强制覆盖恢复**：系统中毒、磁盘损坏等灾难场景专用。

### 7.2 全场景恢复能力

单文件精准恢复、文件夹批量恢复、分区镜像整机恢复、整块硬盘镜像恢复、数据库解密还原、跨设备局域网远程恢复、历史版本时间点回溯、备份包在线预览、PE 裸机整机救援。

### 7.3 强制固定恢复流程

读取加密备份包 → 输入密钥/导入密钥文件解密 → SHA256 完整性校验 → 磁盘空间与权限检测 → 执行数据还原。

## 9. Windows 文件服务器 SMB 审计模块（落尘原创）

### 使用场景

部署在 Windows Server 文件服务器，完整记录内网所有账号对共享目录的全部操作行为，实现全流程可追溯、可预警、可审计。

### 可捕获全部操作行为

- SMB 远程登录：精确到时分秒的接入时间、访问账号、客户端 IP、设备主机名；
- 文件基础操作：读取打开、写入修改、覆盖更新；
- 高危操作：文件拷贝导出、文件/文件夹删除、批量删除、文件移动、重命名；
- 权限操作：文件权限篡改、越权访问失败记录；
- 智能识别风险：批量文件外泄、凌晨非工作时段访问、高频删除行为自动标记风险标签。

### 底层双采集融合方案（原创设计）

- NTFS SACL 安全事件日志：精准持久化存储所有文件操作，作为兜底审计记录；
- ETW 实时事件追踪：低延迟流式采集，风险行为实时触发告警，海量访问场景日志无丢失。

### 模块核心功能

- 一键自动配置服务器安全策略，批量开启共享目录审核规则；
- 区分服务器本地操作与内网客户端远程拷贝外泄行为；
- 单文件全生命周期追溯；
- 日志加密防篡改，本地+远端 NAS 双副本归档；
- 告警联动：高危行为弹窗提醒，同步推送风险日志至全局审计系统；
- 与勒索防护、加密备份模块互通：检测到备份目录异常访问直接触发高危告警。
