## 一、模块定位

LightGuard 备份系统不是普通备份，是一套「Windows 本地 + SMB 局域网私有加密容灾系统」。

核心目标：
- 局域网任何人拿到你的 NAS/共享文件绝对看不懂、打不开
- 勒索病毒无法加密、无法破坏你的备份
- 支持电脑所有粒度备份：文件、目录、分区、整盘、数据库
- 全套进度可视化、日志审计、自动清理、断点续传、版本回溯、裸机恢复

## 二、加密体系（核心重点：局域网防偷看 + 抗勒索）

### 1. 加密算法组合

| 用途 | 算法 | 说明 |
|------|------|------|
| 存储加密（默认） | AES-256-GCM | 加密+完整性校验，防篡改、防勒索二次加密 |
| ARM/低配设备 | ChaCha20-Poly1305 | 自动切换 |
| 国密合规（可选） | SM4 | 对称加密 |
| 密钥派生 | PBKDF2-HMAC-SHA256 | 10万次迭代+随机盐值，抵御彩虹表 |
| 完整性校验 | SHA256 | 分片独立哈希+整包总哈希 |
| 传输加密 | SMB over TLS1.3 | 局域网防抓包 |
| 权限隔离 | RSA2048 | 公私钥分离，员工只能上传无法解密 |

### 2. 抗勒索核心机制（独家）

- 所有备份文件封装自定义后缀 `.lgbackup` 密文格式
- 勒索病毒无法识别、无法加密、无法破坏
- GCM 校验一旦检测篡改直接隔离损坏备份
- 备份密钥永不存储在局域网服务器，只在本机

### 3. 内网防偷看最终效果

局域网任何人登录 NAS/SMB 共享 → 拷贝所有备份文件 → 打开全部乱码、无法解压、无法预览、无法读取 → 无密钥 = 永久无法解密

## 七、加密解密恢复体系

备份流程：读取文件 → VSS快照 → 分片处理 → AES加密 → SHA256校验 → 写入本地/SMB → 日志

恢复流程（强制固定）：
读取加密备份包 → 输入密钥 → 解密校验 → 完整性哈希校验 → 空间检测 → 三种恢复模式

三种恢复模式：
1. 隔离恢复（默认安全）：恢复到新目录
2. 增量恢复：只恢复更新文件
3. 强制覆盖恢复：灾难恢复专用

恢复能力：单文件/目录/分区/整盘/数据库/跨设备/版本回溯/预览/PE裸机
